About & limits

PayGuard AI checks an invoice before you pay. A low score does not mean "safe", and a high score does not prove fraud. The score is a heuristic, not a statistically validated fraud probability. Verification passing means only that the required checks passed — it does not prove the seller is legitimate.

All PayPal transactions in this app are Sandbox tests. No production credentials and no real money are used. Links in invoices are inspected as text and never opened. Instructions hidden inside an invoice are flagged, not followed.

Setup instructions (when credentials are missing)

  • AI: set PAYGUARD_AI_API_KEY in Vercel Environment Variables (Production), optionally PAYGUARD_AI_BASE_URL and PAYGUARD_AI_MODEL (default Groq, openai/gpt-oss-120b), then redeploy.
  • PayPal Sandbox: set PAYPAL_SANDBOX_CLIENT_ID and PAYPAL_SANDBOX_CLIENT_SECRET in Vercel Environment Variables (Production), optionally PAYPAL_SANDBOX_BASE_URL (default https://api-m.sandbox.paypal.com), then redeploy.
  • Never paste keys in chat, frontend code, or the repo. Never use production PayPal credentials.
